# 闲鱼卖家问询话术（可直接复制）

> 配合 `nfc-eink-cross-system-analysis.md` §11 使用。
> **核心原则：先表明要买，再问技术问题；分批问，别一次砸一堆。**
> 闲鱼卖家最烦"只问不买"，但对**懂行的买家**通常很愿意聊——他们也想找同好。

---

## 通用原则

1. **开场必须简短**，并且明确表达购买意向。长篇大论会被直接忽略。
2. **先下单再深聊**。花 ¥2 买片转接板，你从"询价的"变成"客户"，态度立刻不一样。
3. **表现出懂行**。用对术语（FPC 间距、驱动 IC、LUT 波形、SPI），
   对方会判断你是同好而不是小白，愿意给干货。
4. **一次只问 1~2 个问题**，得到回复后再追问。
5. **别提"破解""逆向"**。说"自己做个桌面摆件""想接 ESP32 玩"就行。

---

## 对卖家 A：「3度橙手工DIY」（深圳，卖 24pin 0.5转0.8 转接FPC，¥2）

### 第一条（开场 + 直接下单）

```
老板你好，转接FPC我要5片。

我手上有块华为壳拆下来的3.98寸墨水屏，想接ESP32玩一下。
看你图里那块驱动板是自己配的吗？也出吗？
```

> 💡 **为什么这么写**：一上来就说要 5 片（¥10，对方有动力回），
> 同时亮出"我有屏、我知道是 3.98 寸、我要接 ESP32"，
> 立刻把自己定位成同好。最后那句给了他一个**追加卖你东西**的机会——
> 卖家最愿意回答的就是"还能卖你什么"。

### 第二条（拿到回复后，问最值钱的问题）

```
再请教两个事：

1. 这屏的驱动IC是什么型号？24pin的引脚定义有图吗？
2. 你拆壳的时候，壳里面那颗NFC主控的丝印是什么？
   我想看看是不是启纬（Chivotech）那颗，好奇它怎么无源驱动这么大的屏。
```

> 💡 **第 2 问是整个项目里性价比最高的一个问题。** 他拆过壳，一定见过那颗芯片。
> 一句话就能省掉你自己拆解 + 显微镜看丝印的全部工作，
> 并且直接回答分析文档 §2 的核心悬念。
> 加上"好奇它怎么无源驱动这么大的屏"这种技术感慨，对方更愿意展开聊。

### 第三条（如果聊得投机）

```
你这屏的刷新波形（LUT）是自己调的还是有现成固件？
我看另一个卖家说有个"A0/A1固件"，是同一个东西吗？
```

## 对卖家 B：「爱吃韭菜叠馍的鸢尾」（卖 3.98寸墨水屏成品，支持 A0/A1 固件 + ESP32-C3 mini）

### 第一条（开场）

```
老板你好，你这个3.98寸的，屏+驱动板+ESP32C3一套多少钱？

另外问一下，"A0/A1固件"是指什么？是开源的吗，还是你这边自己写的？
我手上有块同款屏（华为壳拆的），想自己接板子玩。
```

> 💡 **为什么这么写**：先问价（表明要买），紧接着问 A0/A1 固件——
> 这是你最想知道的东西。最后一句"我手上有同款屏"很关键，
> 说明你不是来白嫖固件的，你是真有硬件、可能还会买他的驱动板。

### 第二条（追问）

```
明白了。那几个问题：

1. 固件支持的屏是哪个型号？我这块是552×768四色的，能对上吗？
2. 只买驱动板的话出吗？我屏是现成的。
3. 这屏刷一次全屏要多久？四色的话应该不快吧。
```

> 💡 第 1 问在**验证型号是否一致**——别买回来固件不匹配。
> 第 3 问是闲聊性质的技术问题，用来维持对话温度。

## 想问但要注意分寸的问题

这几个问题**不要在第一轮问**，等混熟了再说：

| 问题 | 风险 | 建议时机 |
|---|---|---|
| "固件能发我一份吗？" | 显得白嫖 | 买了他东西之后 |
| "有没有人搞过NFC那条路，不拆屏直接刷图？" | 偏门，容易被当成奇怪的人 | 聊开之后，当闲聊问 |
| "这屏哪来的货源？" | **敏感，可能涉及来源问题** | ⚠️ 建议别问 |
| "华为那个App的协议你研究过吗？" | 同上 | ⚠️ 建议别问 |

## 期望收获

问完这两家，理想情况下你能拿到：

- ✅ 壳内 NFC 主控的**芯片型号**（→ 直接确定分析文档 §2 的技术路线）
- ✅ 屏的**驱动 IC 型号 + 24pin 引脚定义**
- ✅ **A0/A1 固件的来源**，可能还有固件本身
- ✅ 一套能直接用的**转接板 + 驱动板**
- ✅ 一条进入这个 DIY 小圈子的**人脉**（可能有群）

**总成本：¥10 上下的转接板钱。**

> 最后一条"人脉"别小看。这类小众硬件的关键情报基本都在群里流通，
> 公开搜索引擎索引不到（"A0/A1固件"就是例子）。
> 进了群，你要的答案可能已经躺在聊天记录里了。
