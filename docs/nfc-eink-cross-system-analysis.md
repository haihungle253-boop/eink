> 分析对象：华为 nova 15 系列「彩显屏手机壳」（3.98" 四色墨水屏，552×768，238ppi，宣称
> "NFC 无源传图 / 显示 0 电耗 / 刷图 18 秒 / Porink Pixel 私有协议"）。
> 对照物：微雪（Waveshare）1.54" 无源 NFC 四色墨水屏挂件。

## 0. 结论摘要（TL;DR）

| 问题 | 结论 |
|---|---|
| 物理层是不是被鸿蒙锁死？ | **不是。** 几乎可以肯定是标准 ISO/IEC 14443-A @ 13.56 MHz，任何带 NFC 的安卓手机在链路层都能跟它对上话 |
| 那"绑定鸿蒙"绑在哪？ | 绑在**应用层私有协议**（Porink Pixel）+ 鸿蒙侧的系统服务/图库入口。这两层都是软件 |
| 安卓能不能重写一个 App 驱动它？ | **技术上完全可行**（`NfcA.transceive()` 收发裸帧无需特殊权限），前提是把私有协议逆出来 |

| 值不值得干？ | 见 §7 与 §8。在 ¥22.9 成立的前提下，**值得，且应该买**。风险敞口约等于零 |

## 1. 先泼一盆冷水：¥22.9 这个价格不成立

华为 nova 15 / nova 14 系列的官方「彩显屏手机壳」**定价 ¥299**（随 nova 14 Ultra 一同发布时即为此价）。
拼多多上 ¥22.9 的同名链接，是官方价的 **7.6%**。

单看物料就说不通：

- 3.98" 552×768 四色电子纸面板，**裸屏在小批量渠道就要上百元**；
- 加上 NFC 能量收集 MCU（见 §2）、天线、AG 钢化玻璃后盖、铝合金按键、TPU 壳体；
- 官方标称整重约 59 g。

¥22.9 能覆盖的，只有一个**印了张图的普通 TPU 壳**。这是拼多多上非常典型的
"标题抄官方 / 实物是印刷图案壳"套路——注意那个链接上挂的是平台算法标签
（"多人评价全新未拆封""好评率超99%同款"），不是店铺自证。

> **动手前的验证办法**：问客服要一段"同一个壳先后刷两张不同图"的**连续录像**（不是宣传视频，
> 是实拍，中间不切镜头）。真墨水屏刷图时会有明显的**反色/闪屏过程**，四色屏刷新期间会
> 走一遍红黄黑白的全场刷色，装不出来。对方支支吾吾就是印刷壳。

价格上真正合理的对比是：

| | 华为彩显壳 | 微雪 1.54" 四色挂件 |
|---|---|---|
| 售价 | ¥299（官方） | ¥134.4 |
| 分辨率 | 552×768 | 200×200 |
| 屏幕面积（估算） | ≈ 7.5 in² | ≈ 1.2 in² |
| **单位面积价格** | **≈ ¥40 / in²** | **≈ ¥113 / in²** |

所以"开放系统的微雪要卖六倍价格"这个感受，是拿**假货价**在对比。按面积算，
**华为反而便宜约 3 倍**——这是手机厂拿整机出货量补贴配件 + 大批量采购的结果，
微雪那边是零售小批量 + 开放生态（附 App、文档、SDK）的溢价。这个溢价是真实成本，不是智商税。

## 2. 这类东西到底怎么工作的

理解这一点，才能判断"绑定"绑在哪一层。

### 2.1 供电：NFC 能量收集（Energy Harvesting）

壳里没有电池。手机 NFC 进入 **reader/writer 模式**后持续发射 13.56 MHz 载波，
壳内线圈整流取电，给一颗 **NFC MCU** 供电，由它去驱动电子纸。

这一支的主流芯片是**启纬科技（Chivotech）TurboNFC 系列**，典型型号 **TN2115S2**：

- Cortex-M0 @ 8 MHz，内置 NFC 前端
- **在典型 NFC 手机场下可收集最高约 300 mW**
- 官方定位就写着 "Eink price tags / smartphone accessories"

Aaron Christophel 2023 年逆向微雪 2.13" NFC 墨水屏时，主控无丝印，
最终通过引脚比对锁定的就是 TN2115S2，并用 J-Flash Lite 刷了自制固件。
同类还有复旦微（FM）的 NFC 无源电子纸方案（它家自己上架了 iOS 的 "NFC Eink" App）。

华为这块 3.98" 面板比 2.13" 大得多，很可能用的是同代或更高功率的 NFC MCU，
但**能量收集这条技术路线是同一条**。

### 2.2 通信：ISO/IEC 14443-A

国内几家无源 NFC 电子纸方案商的规格书里写得很直白：
**ISO/IEC 14443-A，13.56 MHz，16 字节 UID，内置约 100 K 存储**，
并且——这点很关键——**支持 RSA / DES / AES / 国密算法的加密通信**（可选）。

也就是说：底层是完全标准的 NFC-A，**加不加密是方案商的选择**。

### 2.3 数据量与 18 秒的合理性

552 × 768 = 423,936 px，四色 = 2 bit/px → **约 103.5 KB**。

- ISO 14443-A 基础速率 106 kbit/s → 理论传输 ≈ 8 s
- 若协商到 424 / 848 kbit/s → 1~2 s
- 四色电子纸整屏刷新本身就要 10~20 s

**18 秒 = 传输 + 刷屏**，数字对得上，说明宣传参数是真实的工程数字，不是编的。
（反过来说，这也佐证真货确实存在，只是不是 ¥22.9 那个。）

## 3. "绑定鸿蒙"到底绑在哪一层

把栈拆开看：

| 层 | 内容 | 是否绑定鸿蒙 | 说明 |
|---|---|---|---|
| L1 射频 | 13.56 MHz 载波 + 能量收集 | ❌ 不绑 | 任何 NFC reader 都能发场 |
| L2 链路 | ISO 14443-A（ATQA/SAK/UID/防冲突） | ❌ 不绑 | 安卓 `NfcA` 直接可读 |
| L3 传输 | 分块写入命令 / 状态查询 | ⚠️ **私有** | "Porink Pixel 私有协议"在这里 |
| L4 鉴权 | 可选的 AES/国密挑战应答 | ⚠️ **未知，最大风险** | 芯片支持，华为是否启用不明 |
| L5 应用 | 图库/备忘录一键同步、圈选抠图 | ✅ 绑 | 纯鸿蒙侧软件，我们自己写 |

**结论：真正的门槛只有 L3 和（可能存在的）L4。**
L5 那些"备忘录一键同步""圈一圈智能抠图"全是鸿蒙侧的 App 逻辑，
在安卓上自己实现甚至能做得更花——图像抖动（dithering）到四色调色板这件事，
用 Floyd–Steinberg + 自定义色板几十行就能出效果。

还有一个有意思的旁证：宣传里写"**无碍其他 NFC 功能使用**"。这说明壳的天线/前端做了
旁路或失谐设计，让手机自己的 HCE（公交、门禁）能穿过壳工作。这是纯硬件设计，
跟操作系统无关——**壳本身没有"认机型"的硬件手段**。

## 4. 三条可行路线

### 路线 A：安卓自写 App + 协议逆向（最"玩具"，也最有成就感）

安卓侧**没有任何系统级阻碍**：
`NfcA.get(tag).transceive(byte[])` 可以收发任意裸帧，不需要 root，不需要特殊权限，
只要 `android.permission.NFC`。微雪那套第三方 App（`joshuatz/nfc-epaper-writer` 及其
`mk-fg` / `DevPika` / `lunarcloud` 分支）就是这么干的，能驱动到 7.5" 面板——
**这证明普通安卓手机的 NFC 场强足以喂饱大尺寸无源电子纸**。

> ⚠️ 但有个已知坑：微雪官方 App 明确写着**不支持三星、Google、索尼手机**。
> 原因就是这几家的 NFC 控制器输出功率/占空比偏保守，收集不到足够能量。
> 你要拿来驱动的那台安卓机，**场强是第一道门槛，不是软件问题**。
> 华为自家手机在这件事上是"特调过"的（它知道背面贴着自家的壳）。

**逆向步骤（按里程碑推进，每一步都可以停）：**

| 里程碑 | 做什么 | 需要什么 | 卡住了说明 |
|---|---|---|---|
| M0 | 用任意安卓机 + NFC Tools 读壳的 ATQA / SAK / UID / NDEF | 一台安卓机 | 读不到 → 不是 14443-A，或者根本没芯片（假货） |
| M1 | 抓一次完整刷图的空口报文 | **Proxmark3**（`hf 14a sniff`）夹在 nova 15 和壳中间 | 抓到但全是高熵数据 → 走了加密，见 M1' |
| M2 | 切分出「命令头 / 分块地址 / 图像负载」结构 | 对比刷两张已知图（纯黑、纯白）的报文 diff | 纯黑/纯白报文差异不呈规律 → 有压缩或加扰 |
| M3 | 用安卓 `NfcA.transceive` 原样重放，看屏幕是否刷新 | 一个 50 行的 Demo App | 重放失败 → 有 nonce/计数器，即存在鉴权 |
| M4 | 参数化：自己生成图 → 抖动到四色 → 分块发送 | Floyd–Steinberg + 调色板 | — |
| M1' | 若加密：逆鸿蒙侧的 HAP（ArkTS 字节码或原生 .so），找密钥/算法 | Ghidra + HAP 解包 | 密钥在 TEE / 芯片内 → **到此为止，放弃** |

**成功概率主观评估：**
- 无鉴权、纯明文分块写入 → **能做成，概率我给 60%**（这类方案为了省成本，绝大多数不开加密）
- 有鉴权但密钥硬编码在 App 里 → 还有戏，概率 20%
- 密钥在 TEE / 芯片安全区 → 0%，直接收工

### 路线 B：PC / 专用读写器驱动（绕开手机场强问题）

如果安卓机场强不够，可以上 **Proxmark3** 或 **ST25R3916 系列**（Flipper Zero 用的就是它）
外接高功率天线。参考点：
- Flipper Zero 的 `nfc_eink` App（`RebornedBrain/nfc_eink`，已进官方固件）已能**写入**
  微雪 2.13/2.7/2.9/4.2/7.5" 和 Good Display GDEY 系列，也能**模拟**这些屏来抓 App 发的数据
  —— 这是个极好的"逆向 + 复现"工作流参考：**先用 Flipper 模拟一块屏，把官方 App 发的东西录下来**。
- Proxmark3 固件里甚至内置了 `hf waveshare` 命令。

但注意：Flipper/PM3 的**取电能力弱于手机**（手机 NFC 天线大、功率预算宽），
驱动 1.54" 没问题，**3.98" 四色屏能不能喂饱是个真实的未知数**，可能需要外接供电的读写器天线。

### 路线 C：不折腾，直接买开放生态的（最省心）

已经存在一整个"通用无源 NFC 墨水屏手机壳"白牌市场，**自带安卓/iOS App，不挑机型**：

- 1688 / 淘宝上的 **4.0" 无源 NFC 电子纸手机壳方案**（黑白红，800×480，甚至是给 iPhone 做的）
- **SpaceInk**（Google Play 有安卓 App，专门配墨水屏手机壳）
- **Smart Case - NFC Ink Screen**（App Store）
- **NFC Eink**（App Store，复旦微电子出品）
- 微雪 / Good Display 系列（有 wiki、有 Android SDK、有第三方开源 App、有 Flipper 支持）

**这条路的性价比其实最高**：白牌 4 寸方案的价格远低于微雪零售价，又不用逆任何东西。

## 5. iOS 和其他系统

- **iOS**：CoreNFC 的 `NFCTagReaderSession` 支持 `.iso14443`，可以通过
  `sendMiFareCommand` / APDU 通道发裸命令。微雪有官方 iOS App，复旦微也有——
  **说明 iOS 上路是通的**，只是 Apple 对场持续时间和会话时长管得更严，
  大面板刷图（十几秒）容易撞上会话超时，需要分段续场。
- **Web NFC（Chrome on Android）**：❌ 不行。Web NFC 只能读写 **NDEF**，
  而图像传输走的是 NDEF 之下的裸命令。这条路直接堵死。
- **Linux / PC + PN532**：协议层没问题，**功率层大概率不够**（PN532 模块天线小、功率低）。
  ACR122U 同理。要上就上 PM3 / ST25R3916 + 大天线。

## 6. 一个容易被忽略的物理问题

**这个壳只适配 nova 15 / 15 Pro / 15 Ultra 的模具。**

如果你的主力机不是 nova 15，那么即便协议逆通了，你也只能：
1. 把壳当成一块**独立的 NFC 墨水屏牌子**，刷图时把它贴到手机 NFC 天线位置（能用，但就不是"手机壳"了）；
2. 或者把电子纸模组从壳里**拆出来**做别的（DIY 冰箱贴/桌牌/名牌）——
   这其实是最有意思的玩法，一块 ¥299 的 3.98" 四色无源电子纸模组，
   在开放市场上是买不到这个价的。

另外壳内 NFC 线圈的位置是**照着 nova 15 的 NFC 天线位置对齐的**，
换台手机要自己摸索耦合位置，可能要贴偏一点才刷得动。

## 7. 我的建议

**如果你的目的是"买个能玩的无源墨水屏"** → 走**路线 C**。
白牌 4 寸 NFC 无源电子纸手机壳方案，自带通用 App，几十到一百多块，
今天买明天就能用，不用逆任何东西。微雪那个 ¥134 的 1.54" 挂件贵在小尺寸+零售，
但胜在文档/SDK/开源生态完备（Flipper、Proxmark3、三个开源安卓 App 都支持），
适合当"确定能跑通"的入门件。

**如果你的目的是"折腾一个没人逆过的东西"** → 走**路线 A**，但先做这两件事：
1. **确认货是真的**（§1 的录像验证法），或者干脆去华为官方渠道买 ¥299 的正品；
2. **先花 ¥134 买微雪那个挂件当练手靶子**——它协议公开、有开源实现、有 Flipper 支持，
   你可以先把"安卓 App 收发裸帧 → 图像抖动 → 分块写入"的整条链路跑通。
   这条链路在华为壳上是**同一套代码骨架**，只是命令字不同。
   练手件跑通了，再去啃 Porink Pixel，才不会一上来就卡在"到底是我代码错了还是协议不对"。

**明确的劝退信号**（出现任何一个就收手）：
- Proxmark3 抓到的报文高熵、纯黑图和纯白图的报文没有明显规律 → 加密了
- 原样重放不生效 → 有 nonce / 防重放
- 鸿蒙侧刷图逻辑不在 HAP 里、而是走系统服务或 TEE → 密钥摸不到

## 8. 修订评估（2026-08-18：使用者已实物核实屏幕为真）

§1 的价格质疑作废。以下按"¥22.9 确实能买到真的 3.98" 四色墨水屏"这个前提重推一遍。
**这个事实不是中性的，它显著改变了技术判断——而且是往有利方向。**

### 8.1 ¥22.9 的真屏意味着什么

它几乎不可能是华为官方零售渠道的 ¥299 正品。合理的来源只有这几种：

1. **同一 ODM（Porink）的白牌版 / 外流工程料**——同方案同模具，去掉华为 logo 和定制固件；
2. **nova 14 代的清仓尾货**——上一代模具，面板方案不变；
3. **退货/翻新件**（那个"全新未拆封"标签是个提示）；
4. **B 品面板**（有坏点、色偏，或刷新次数已耗一部分）。

**这四种情况里，前两种对逆向是重大利好。** 原因：

> 白牌 / ODM 出货的方案，**基本不会启用加密通信**。
> §2.2 提到这类芯片支持 AES/DES/RSA/国密——但启用加密意味着方案商要给每个客户做密钥
> 灌装、管理和售后，成本和麻烦都是实打实的。**只有华为这种自己定制固件的大客户才会做。**
> 你手上这个如果是白牌流出的，**大概率是明文协议**。

**因此我把 §4 路线 A 的成功概率从 60% 上调到约 75%。**

### 8.2 而且可能根本不用逆向：先试现成的 App

存在一整条**白牌 3.7"/4.0" 四色 NFC 墨水屏手机壳**的成熟生态，全都自带通用 App、不挑机型：

| App | 平台 | 备注 |
|---|---|---|
| **Clever Play**（XCOOL InkPlay 配套） | iOS / Android | 白牌 iPhone 墨水屏壳生态里最常见的一个 |
| **Smart Case - NFC Ink Screen** | iOS | 开发者 "波宁" —— **拼音疑似对应 Porink，重点怀疑对象** |
| **SpaceInk** | Android（Google Play） | 专门配墨水屏手机壳 |
| **NFC Eink** | iOS | 复旦微电子出品，配它家 NFC 无源电子纸方案 |
| KSOPUERT / nexlenz 等配套 App | iOS / Android | 同一批白牌方案，3.7 寸四色，规格与华为这块极接近 |

**"Smart Case - NFC Ink Screen" 的开发者署名是"波宁"，而壳上印的协议叫 "Porink Pixel"。**
这个拼音对应关系值得优先验证——如果 Porink 就是波宁，那么**同一家厂商已经有一个公开的
第三方 App 在 App Store 上了**，你的壳可能开箱即用，整个逆向工程直接跳过。

> **所以拿到货的第一件事不是抓包，是拿这几个 App 一个个去怼它。**
> 十分钟的事，运气好直接省掉后面所有工作。这是本次修订里最有价值的一条。

## 10. 配套 App「墨有引力」：能不能装到非华为机上

**已知：** 配套 App 叫**「墨有引力」**，只在华为应用市场（AppGallery）能搜到。
我在酷安、APKPure、应用宝等第三方渠道都没有搜到它——**这个"搜不到"本身就是一条重要证据**，
指向它是 HarmonyOS 原生应用而非传统 APK。

**另外注意这个名字。** 华为官方配件的 App 会叫「智慧生活」或者直接集成进系统图库，
不会起「墨有引力」这种谐音梗名字。**这强化了 §8.1 的 ODM 白牌判断**——
也就是说，协议里大概率没有华为的定制加密。

### 10.1 先分诊：它是 APK 还是 HAP？

**这一个问题决定后面的全部路径，先花五分钟搞清楚。**

| 判定方法 | 怎么做 | 结论 |
|---|---|---|
| A. 看商店详情页 | 华为应用市场里找「墨有引力」，看是否带 HarmonyOS 标识 / 写着「仅支持 HarmonyOS NEXT」/ 归在「元服务」 | 有 → HAP |
| B. 在非华为安卓上试 | 装华为应用市场 APK（见 10.2），搜「墨有引力」 | 搜不到或显示"不兼容" → HAP；能下能装 → APK |
| C. 看机型要求 | 是否只有 HarmonyOS 5 的机器（nova 14/15 等）才出现 | 是 → 几乎确定 HAP |

> ⚠️ **如果是 HAP，必须接受一个事实：它在安卓上永远跑不起来。**
> HarmonyOS 5（NEXT）的应用是 ArkTS 字节码（`.abc`）跑在方舟运行时上，
> 和 Android 的 ART / Dalvik 是两套完全不同的东西。
> **没有兼容层，没有模拟器，没有"装个什么就能跑"的办法。** 这条路是死的，别浪费时间找。
>
> 但——**这不影响你的最终目标**，见 §10.4。

### 10.2 如果是 APK：怎么装到非华为机上

按成功率从高到低：

| # | 办法 | 说明 |
|---|---|---|
| 1 | **装华为应用市场本体** | AppGallery 的 APK 在 `consumer.huawei.com` 官网可下，**任何安卓机都能装**。装完搜「墨有引力」 |
| 2 | **AppGallery 网页版** | `appgallery.huawei.com` 上应用有网页详情页，APK 类应用常有直链 |
| 3 | **从华为机上 adb pull** | `adb shell pm path <包名>` 拿到路径，再 `adb pull`。得到原始 APK |
| 4 | 第三方镜像站 | 酷安 / APKPure / 应用宝。**我已搜过，目前没有**——所以这条基本指望不上 |

**装上之后可能撞的三道坎：**

| 坎 | 现象 | 解法 |
|---|---|---|
| **HMS Core 依赖** | 启动就提示"请安装华为移动服务" | 装 HMS Core APK。新版本对非华为机限制变严，不一定成 |
| **机型白名单** | 能启动但提示"不支持当前设备" | App 里查 `Build.MANUFACTURER` / `Build.MODEL`。用 **LSPosed 改机型**，或 apktool 改字节码后**重新签名**。这类检查通常很粗糙，好绕 |
| **华为私有 NFC 接口** | 刷图时直接崩溃 | 如果它调了华为私有的 NFC 高功率 API，在别家机上无解。**这道坎才是真的坎** |

### 10.3 最省事的一条：直接问卖家

白牌卖家的包装盒里**经常附一个 APK 下载二维码**。直接问客服：

> "有没有安卓版 App？给个 apk 下载链接。"
> "除了墨有引力，还有别的 App 能刷吗？"

同一个 ODM 通常会给不同客户做不同皮的 App（`SpaceInk`、`Clever Play` 那一批就是这么来的），
**换个皮，底下是同一套协议**。问出来就赚了。

### 10.4 ⭐ 关键重构：你不需要"运行"它，你需要的是协议

**这是本节最重要的一段。**

拿到安装包的真正价值，是**把它丢进反编译器**，不是把它跑起来。
而这件事——**APK 和 HAP 都能做**。

#### 如果拿到 APK

```
jadx-gui 墨有引力.apk
```
然后搜这些关键词：`NfcA`、`transceive`、`connect()`、`getTechList`、
`byte[]` 形式的命令常量、`0x` 开头的魔数、`epd` / `eink` / `refresh` / `lut`。

**这一步做完，Proxmark3 就不用买了**——协议直接摆在你面前。

#### 如果拿到 HAP —— 一样能拆

**`.hap` 本质就是一个 zip**，`unzip` 开来看：

| 路径 | 里面是什么 | 价值 |
|---|---|---|
| **`libs/arm64-v8a/*.so`** | 原生库 | ⭐⭐⭐ **重点。国产 NFC/EPD SDK 十有八九是 `.so`**——因为厂商要在 Android / HarmonyOS / iOS 三端复用同一份 C 代码。**这个 `.so` 丢进 Ghidra，协议就在里面**，而且它和 Android 版是同一份代码 |
| `ets/modules.abc` | ArkTS 字节码 | ⭐⭐ 有 `abcde` 等反汇编工具，生态不算成熟但能读出字符串和调用结构 |
| `resources/` | 资源 | ⭐⭐ 可能藏着面板参数表、波形 LUT、支持机型列表 |
| `module.json5` | 清单 | 看权限声明、有没有 NFC 相关的私有权限 |

> **所以：即使它是 HAP，即使你永远装不上，目标依然达成。**
> 你要的是那串命令字节，不是那个界面。界面你自己写一个更好看的。

### 10.5 怎么搞到 HAP 文件（手上没华为机的话）

- **借一台 HarmonyOS 5 的机器**（任意型号都行，**不必是 nova 15**），
  开发者模式 + `hdc`（华为版 adb）：`hdc file recv <路径>`。
  这比 §9 里"借 nova 15 抓包"容易得多——不挑机型，也不用壳在场。
- 或者去酷安 / 贴吧 / 相关群里找人帮忙 dump 一份。
- 华为开发者联盟的开发者账号也能从后台看到部分应用包信息。

### 10.6 修订后的行动顺序

把 §8.5 的 Day-0 清单更新为：

| 步骤 | 操作 | 成本 |
|---|---|---|
| 1 | **问卖家要安卓版 apk 链接 / 其他可用 App** | ¥0，一句话 |
